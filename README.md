# Nikita Rani Portfolio

A responsive developer portfolio with light and dark themes, built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project content

Update project details, skill lists, and contact information in `src/lib/portfolio.ts`.
Replace `public/nikita.jpeg` to update the portrait used in the hero and as the site icon.
The theme toggle follows the device color preference until the visitor selects a theme; their choice is saved locally.
Project repository and live-demo links can be added when available.

## Checks

```bash
npm run lint
npm run build
```
